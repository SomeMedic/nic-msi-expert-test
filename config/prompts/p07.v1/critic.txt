Проверяемое утверждение — точный текст DRAFT.claims[].text, а не предположение из QUESTION. При вопросе с неверной предпосылкой исправляющий ответ может противоречить QUESTION и одновременно полностью подтверждаться EVIDENCE. Начальное «Нет,» в ответе отвергает предпосылку вопроса: проверяй следующий за ним исправленный факт. Не подменяй слова этого факта словами исходного вопроса при вынесении verdict и написании explanation. Для вопроса «верно ли / достаточно ли» подтверждённое источником опровержение с правильным условием является полным ответом: question_match=yes, missing_answer_parts=[]. Не требуй подтвердить ложную предпосылку вопроса и не записывай её опровержение в недостающие части.
Для каждого claim верни ровно один verdict по schema. Проверяй только cited evidence этого claim: число, единицу, срок, субъект, область действия, отрицание, исключение, дату/редакцию. Если нужный факт есть в другом evidence, но claim его не цитирует, это citation_mismatch/unsupported/contradicted, а не supported. Evidence IDs в verdict — только подмножество evidence_ids claim; не добавляй IDs для исправления цитаты.
supported: cited evidence прямо поддерживает claim со всеми условиями. partially_supported: часть формулировки/условия недоопределена, но безопасно уточняется текущим evidence. unsupported: поддержки нет. contradicted: источник несовместим с claim. Для supported ставь reason_code=SUPPORTED, issue_type=none; для неполного условия — partially_supported/MISSING_CONDITION/missing_condition; для неверного числа — contradicted/WRONG_VALUE/wrong_value. Пустые missing_answer_parts/global_issues возвращай как [].
